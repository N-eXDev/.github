## ✦ Who We Are

**N-eX Dev** is a software dev club for enthusiasts — a small crew that builds things,
breaks things, and figures it out as we go. Started in India in November 2023, run by
developers who would rather ship than theorise.

> **What we stand for:** *embrace the lore, ship the code* — build it, break it, learn it
> in public, and pass it on. No gatekeeping, no half-finished excuses.

- 🛠️ **Ship real projects** — working demos beat slide decks
- 🌱 **Learn in public** — beginners are the point, not the problem
- 🔓 **Open by default** — share the process, hand over the keys
- ⚡ **Embrace the lore** — the deep rabbit holes are the best part

## 🤝 Contributing

Pick a repo, open an issue, send a PR. That's the whole process.

1. **Fork** the repo you want to work on and create a branch: `git checkout -b your-feature`
2. **Keep it runnable** — if it doesn't build locally, it doesn't get merged
3. **Match the existing style** — we follow whatever the repo already does
4. **Write the commit message for a human** — explain *why*, not just *what*
5. **Open a PR** and describe what you changed and how you tested it

**Ground rules**

- Be decent. Critique the code, never the person.
- Beginners get patient reviews, not gatekeeping.
- Ask before you rewrite someone else's architecture.
- Credit stays with whoever did the work.

Something not listed? Open an issue and tell us — new project proposals are welcome.
